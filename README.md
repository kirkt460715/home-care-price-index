# 居家服务采购价格指数的规格衔接与合同调价

居家服务采购研究资料。金额以分为单位，月份按北京时间。spec 可区分计量单位与是否含交通。linked_group 相同的记录可能引用同批交易，按凭证引用确定合计使用的权重。系列已公示的基准指数为其基期的 100。合同调价是采购单价调整，记录中的调价限幅是比例。

资料均为合成记录，采用 UTF-8 编码。交换字段、标识和状态见[资料说明](docs/data.md)。

项目使用 Python 3.11.2，资料查看与检测只依赖标准库。在项目目录运行以下命令，可查看各集合的记录数，并检查字段、重复键与跨表引用。

```sh
python3 inspect_records.py
python3 -m unittest discover -s tests -v
```
